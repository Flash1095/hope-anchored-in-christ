Think on These Things

Command
Think on These Things
Category
Apostolic Commands
Summary
Paul's thought command: whatever things are true, honest, just, pure, lovely, and of good report — think on these things.
Commandment
Finally, brethren, whatsoever things are true, whatsoever things are honest, whatsoever things are just, whatsoever things are pure, whatsoever things are lovely, whatsoever things are of good report; if there be any virtue, and if there be any praise, think on these things.
Scripture
Philippians 4:8
Application
The mind is given a menu, not a vacuum: attention is itself obedience. What is dwelt on becomes what is done, which is why the verse follows 'those things do'.
Related Topics
Wisdom; Holiness; Peace
Related Books
Philippians
Related People
Paul
Purpose
TRADITIONAL reading: to train attention, since thought is the seedbed of action.
Duration
