Do not castrate any animal

Command
Do not castrate any animal
Category
Ceremonial Law
Summary
The command: Do not castrate any animal (Leviticus 22:24). No beast was to be bruised, crushed, broken, or cut, whether for offering or otherwise, in the land.
Commandment
Do not castrate any animal.
Scripture
Leviticus 22:24
Application
This prohibition is stated generally, not only for the altar, and so it binds beyond the temple system.
Related Topics
Sacrifice
Related Books
Leviticus; Hebrews
Purpose
TRADITIONAL reading: mutilating an animal marred God's creation and disqualified it from the altar; the prohibition is stated generally, not only for sacrifices.
Duration
For all time
