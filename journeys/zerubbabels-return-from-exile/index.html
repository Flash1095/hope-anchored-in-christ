Scripture
Ezra 1:1-11; Ezra 2:1-70; Ezra 3:1-13
Summary
Under Cyrus's decree, Zerubbabel and Jeshua led the first return of exiles from Babylon to Jerusalem with the temple vessels, rebuilt the altar, and laid the temple foundations amid both joy and weeping. The text names no stops on the return road.
Significance
The first return turns Cyrus's decree into worship: an altar before a temple, and foundations before walls.
