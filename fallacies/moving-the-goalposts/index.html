Moving the Goalposts

Changing the standard of proof after the original standard has been met, so the other side can never succeed. The target keeps shifting.

Example

A manager asks for ten sales, gets ten, then says only twenty would really prove the employee is doing well.

Faith Discussion Example

A skeptic asks for one good manuscript reason to trust a Gospel, is given several, then says none of it counts unless there is video evidence from the first century.

How To Respond

Name the original standard with grace: 'We started with that first request — since we have looked at it, could we agree on what would count as a fair next step?'
