Moralistic Fallacy

Category
Weak Induction
Definition
Arguing that something is not so because it ought not to be so. What we wish were true does not change what is.
Example
Someone argues, 'The world should be fair, so this unfair outcome can't be real.'
Faith Discussion Example
Someone argues, 'God is good, so suffering can't be part of his plan.'
Fallacy
Moralistic Fallacy
How To Respond
Face the facts first: 'What we wish were true doesn't change what is — let's face the facts.'
