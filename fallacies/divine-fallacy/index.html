Divine Fallacy

Category
Presumption
Definition
Assuming a supernatural cause merely because no natural explanation is at hand. A gap in knowledge is not evidence for any particular cause, and it must not be confused with positive arguments from evidence.
Example
Someone argues, 'Science can't explain this yet, so it must be a miracle.'
Faith Discussion Example
Someone argues, 'No one can explain this healing, so it proves this doctrine' — the gap alone proves no doctrine.
Fallacy
Divine Fallacy
How To Respond
Ask for positive reasons: "A gap in our knowledge isn't evidence for any particular cause — let's look for positive reasons."
