Undistributed Middle

Category
Formal
Definition
An invalid syllogism: all A are B; C is B; therefore C is A. Sharing a property with a group does not place something inside that group.
Example
Someone argues, 'All birds have wings. Bats have wings, so bats are birds.'
Faith Discussion Example
Someone argues, 'All Christians pray. He prays, so he must be a Christian' — prayer alone does not establish it.
Fallacy
Undistributed Middle
How To Respond
Name the gap gently: 'That shows a shared trait, not the same group — what else would confirm it?'
