Appeal to Probability

Category
Weak Induction
Definition
Treating mere possibility as probability — because something could happen, it is treated as if it will. Possibility alone sets no odds.
Example
Someone argues, 'This bridge could collapse, so we must never cross it.'
Faith Discussion Example
Someone argues, 'Someone could be offended, so we must never preach.'
Fallacy
Appeal to Probability
How To Respond
Ask the odds: "Possibility isn't probability — how likely is it, really?"
