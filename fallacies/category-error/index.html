Category Error

Category
Weak Induction
Definition
Applying a concept to the wrong kind of thing, so the question itself is malformed. The error lies in the categories, not in the answer.
Example
Someone asks, 'What color is the number seven?'
Faith Discussion Example
Someone asks, 'How much does God weigh?'
Fallacy
Category Error
How To Respond
Reframe the question: 'The question mixes categories — let's ask it in terms that fit.'
