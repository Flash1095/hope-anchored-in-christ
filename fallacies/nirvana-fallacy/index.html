Nirvana Fallacy

Category
Weak Induction
Definition
Rejecting a real solution because it is imperfect, by comparing it with an idealized alternative. Perfect is not the standard; better than the alternatives is.
Example
Someone argues, 'This policy won't end poverty completely, so it's worthless.'
Faith Discussion Example
Someone argues, 'This church isn't perfect, so it's not a real church.'
Fallacy
Nirvana Fallacy
How To Respond
Reset the standard: "Perfect isn't the standard — is it better than the alternatives?"
