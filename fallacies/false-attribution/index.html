False Attribution

Category
Presumption
Definition
Crediting a claim, quotation, or idea to the wrong source, then leaning on that false authority. The error is factual, but it corrupts the argument built on it.
Example
Someone argues from 'Let them eat cake,' a line Marie Antoinette never said.
Faith Discussion Example
Someone quotes 'God helps those who help themselves' as Scripture — it is not in the Bible at all.
Fallacy
False Attribution
How To Respond
Check the source first: "Let's check who actually said it before leaning on it."
