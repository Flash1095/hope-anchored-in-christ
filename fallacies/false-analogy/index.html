False Analogy

Category
Presumption
Definition
An analogy that breaks at the very point it needs to hold. Analogies prove only through the points that genuinely match.
Example
Someone argues, 'The brain is like a computer, so it must have a delete key.'
Faith Discussion Example
Someone argues, 'God is like a father, so God must get tired like fathers do.'
Fallacy
False Analogy
How To Respond
Find the break: 'Analogies prove by the points that match — where does this one break?'
