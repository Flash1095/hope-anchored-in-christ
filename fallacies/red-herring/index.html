Red Herring

Fallacy
Red Herring
Category
Relevance
Definition
Introducing an unrelated topic to distract from the original issue, so the conversation drifts away without answering the question at hand.
Example
When asked about a missed deadline, an employee starts talking at length about how unfair the office parking is.
Faith Discussion Example
Asked about a difficult Bible passage, someone changes the subject entirely: 'Well, what about all the bad things done in the name of religion?' — an important topic, but a different one.
How To Respond
Honor the new topic while returning kindly: 'That is worth discussing too. Could we finish this question first, then come back to that one together?'
