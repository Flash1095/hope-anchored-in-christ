Definist Fallacy

Winning an argument by defining a key term in a way that already assumes the conclusion. The definition does the arguing instead of the evidence.

Example

Someone argues, 'Real freedom means doing whatever you want, so laws destroy freedom.'

Faith Discussion Example

Someone argues, 'True faith means never doubting, so doubters have no faith.'

How To Respond

Agree definitions first: "Let's agree on definitions from shared usage, not from the conclusion we want."
