Equivocation

Fallacy
Equivocation
Category
Ambiguity
Definition
Using the same word in two different senses within one argument, so the conclusion appears to follow when it does not. The meaning shifts midway.
Example
Someone argues, 'A mouse needs cheese, and this computer mouse is a mouse, so it needs cheese,' shifting between animal and device.
Faith Discussion Example
In a faith talk, 'faith' shifts between 'trust based on reasons' and 'believing without any reason,' so a claim about blind belief is used to dismiss trusting faith.
How To Respond
Define terms together early: 'We may be using that word differently — could we pause and agree on what we each mean by it here?'
