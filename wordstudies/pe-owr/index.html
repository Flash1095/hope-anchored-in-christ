Pᵉʻôwr

Word
פְּעוֹר
Language
Hebrew
Transliteration
Pᵉʻôwr
Strongs Number
H6465
Definition
Peor, a mountain East of Jordan; Baal Peor, (for a deity worshipped there
Part Of Speech
proper noun
Biblical Usage
Peor = "cleft"; n pr loc; 1) a mountain peak in Moab belonging to the Abarim range and near Pisgah; n pr deity; 2) a false god worshipped in Moab; corresponds to Baal
