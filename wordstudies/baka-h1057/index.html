bâkâʼ

Word
בָּכָא
Language
Hebrew
Transliteration
bâkâʼ
Strongs Number
H1057
Definition
the weeping tree (some gum-distilling tree, perhaps the balsam)
Part Of Speech
noun (masculine)
Biblical Usage
1) balsam tree-a shrub which drips sap when it is cut; 2) possible name of a vale of balsam trees in Ps 84:6
