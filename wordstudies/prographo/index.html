prográphō

Word
προγράφω
Language
Greek
Transliteration
prográphō
Strongs Number
G4270
Definition
from G4253 and G1125; to write previously; figuratively, to announce, prescribe:--before ordain, evidently set forth, write (afore, aforetime).
