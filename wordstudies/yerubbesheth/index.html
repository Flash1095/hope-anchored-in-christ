Yᵉrubbesheth

Word
יְרֻבֶּשֶׁת
Language
Hebrew
Transliteration
Yᵉrubbesheth
Strongs Number
H3380
Definition
Jerubbesheth, a symbolic name for Gideon
Part Of Speech
proper noun (masculine)
Biblical Usage
Jerubbesheth = "shame will contend"; 1) a variant name of Jerubbaal (the other name of Gideon [ H03378]) substituting the word 'shame' for the name of the pagan god 'Baal'
