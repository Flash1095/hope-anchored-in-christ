hikanós

Word
ἱκανός
Language
Greek
Transliteration
hikanós
Strongs Number
G2425
Definition
from ἵκω (ἱκάνω or ἱκνέομαι, akin to G2240) (to arrive); competent (as if coming in season), i.e. ample (in amount) or fit (in character):--able, + content, enough, good, great, large, long (while), many, meet, much, security, sore, sufficient, worthy.
