dâgal

Word
דָּגַל
Language
Hebrew
Transliteration
dâgal
Strongs Number
H1713
Definition
to flaunt, i.e. raise a flag; figuratively, to be conspicuous
Part Of Speech
verb
Biblical Usage
1) to look, behold; 1a) (Qal) looked at, conspicuous (participle); 2) to carry a banner or standard, set up banner or standard; 2a)(Qal) to set up standard (in battle); 2b) (Niphal) supplied with banners, bannered
