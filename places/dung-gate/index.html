Dung Gate

View on map →

Name
Dung Gate
Modern Location
Jerusalem
Testament
Old
Timeline Era
Return and Second Temple
Description
A gate of Jerusalem repaired by Malchiah son of Rechab, ruler of Beth-haccherem, with the dung gate's thousand cubits of wall unto the fountain gate, and passed in the dedication procession.
Biblical Significance
The Dung Gate is Nehemiah's unglamorous gate: the gate for refuse, repaired like the grand gates, and walked in the same thanksgiving procession.
Key Scriptures
Nehemiah 3:13; Nehemiah 3:14; Nehemiah 12:31
