Holon in Moab

View on map →

Name
Holon in Moab
Modern Location
Unknown; in Moab, Jordan
Testament
Old
Timeline Era
Divided Monarchy
Description
A town named among the plain-country towns of Moab on which judgment is pronounced in Jeremiah 48, listed with Jahazah and Mephaath — a Moabite Holon, distinct from the town of the same name in Judah's hill country.
Biblical Significance
Its single appearance is in the oracle against Moab, showing the name Holon belonged to a Moabite town as well as to Judah's.
Key Scriptures
Jeremiah 48:21
