Name

Modern Location

Testament
Old
Timeline Era
Divided Monarchy
Description
Sepharad was a place of exile where captives of Jerusalem were settled, named in Obadiah's oracle as the home of a captivity that would possess the cities of the south.
Biblical Significance
Sepharad is an exile name: a distant settlement whose captives, Obadiah says, would return to possess the south.
Key Scriptures
Obadiah 1:20
